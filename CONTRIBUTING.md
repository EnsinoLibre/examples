# Contributing a worksheet

Thank you for thinking about sharing your worksheet with other teachers. You do not need to know how to code to contribute here. If you can write a worksheet and click around a website, you can do this.

Here's how, step by step.

## 1. Decide where it belongs

Worksheets are organized as `subject/grade-N/your-worksheet.md`. For example, a grade 4 worksheet about multiplication would live at `math/grade-4/multiplication.md`.

Look through the existing folders first. If the subject or grade you need doesn't exist yet, that's fine, you can create it. Just follow the same pattern (lowercase, words separated by hyphens, like `language-arts/grade-1/`).

## 2. Write your worksheet

Write your worksheet as a plain text or Markdown (`.md`) file. A good worksheet include:

- A title, subject, and grade at the top
- A short learning objective (what should students be able to do after this?)
- The actual questions or activities
- An answer key at the bottom
- A short "Teacher notes" section: how long it takes, and anything worth reviewing before class

The easiest way to get this right is to copy the structure of an existing worksheet and swap in your own content. [math/grade-3/fractions-intro.md](math/grade-3/fractions-intro.md) is a good one to use as a template.

Make sure the worksheet is your own original work, or something you have the rights to share (see the license note below).

## 3. Add it to GitHub

You have two options, pick whichever feels easier:

- **No git needed:** Go to this repo on GitHub, navigate to (or create) the right subject/grade folder, then click **Add file > Create new file**. Type the file path (like `math/grade-4/multiplication.md`) and paste in your worksheet. GitHub will let you do all of this right in your browser.
- **If you're comfortable with git:** fork the repo, add your file, and open a pull request.

## 4. Submit it

Once your file is created (or your pull request is open), submit it for review. A maintainer will take a look. We're reviewing for clarity and whether it fits the collection, not for perfection, so don't worry about making it flawless before you submit.

## 5. A note on licensing

By contributing, you agree that your worksheet is shared under the [CC BY-SA 4.0 license](LICENSE), the same license that covers the rest of this repo. That means other teachers can use, adapt, and share it, as long as they credit you and share their versions under the same license.

Please only submit worksheets that are your own original work, or work you have the rights to share this way. Don't submit content copied from a textbook, workbook, or another website unless you're sure it's licensed to allow that.

## General community norms

For broader guidelines that apply across all EnsinoLibre projects, see the [org-wide CONTRIBUTING guide](https://github.com/ensinolibre/.github/blob/main/CONTRIBUTING.md).

Questions? Ask in [GitHub Discussions](https://github.com/orgs/ensinolibre/discussions), we're glad to help.
